# GameInteractiveTechnology
 본 연구는 Unity에서 Tobii Eye Tracker를 연동하여, 사용자의 시선 데이터를 기반으로 실시간으로 밝기를 조절하는 기능을 구현하고, 해당 시스템의 효과성과 정확도를 검토하는 것을 목표로 한다. 기존의 수동 밝기 조절 방식은 조작 과정이 번거롭고, 사용자마다 시각 인지 능력에 차이가 있어 일관된 사용자 경험을 제공하는 데 어려움이 있다. 이를 해결하기 위해 본 프로젝트는 사용자의 시선을 추적해 오브젝트를 인식할 수 있는 밝기의 임계점을 파악하고, 그 정보를 바탕으로 자동으로 밝기를 조정하는 시스템을 설계하였다. 실험은 세 가지 조건(동적으로 움직이는 오브젝트 추적, 정적 오브젝트 인식, 수동 밝기 설정 테스트)에서 수행되었으며, 자동 조절 기능과 기존 방식 간의 정확도와 사용자 만족도를 비교 평가하였다. 실험 결과, 제안된 시선 기반 자동 밝기 조절 시스템은 사용자 몰입도를 높이고 시각적 피로를 줄이는 데 긍정적인 영향을 주었으며, 향후 VR/AR 환경이나 접근성 보조 기술에 유용하게 적용될 가능성을 보여주었다.
